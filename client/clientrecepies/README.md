# Sweet Recipes client

React front end of the baking expert system. See the [project README](../../README.md) for the architecture and how to run the whole app.

```bash
npm install
npm start                      # http://localhost:3000
npm test -- --watchAll=false
npm run build
```

Set `REACT_APP_API_URL` to point the client at an API other than `http://localhost:7000`.
